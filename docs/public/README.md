# Public Assets Directory

This directory contains static assets that will be served at the root of the documentation site.

## Files

-   `logo.svg` - The main Trific logo displayed in the site header
-   `favicon.ico` - The site favicon shown in browser tabs

## Usage

Files in this directory are automatically copied to the root of the built site and can be referenced directly:

```markdown
![Logo](/logo.svg)
```

## Customization

Replace `logo.svg` with your actual Trific logo and update `favicon.ico` with your brand favicon for a more professional appearance.
