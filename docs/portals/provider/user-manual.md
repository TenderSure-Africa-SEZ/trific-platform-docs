## Getting Started

### Account Registration

1. **Access Registration**

    - Navigate to TRIFIC landing page
    - Click "Join" to navigate to the registration page
    - Select register as Service Provider

2. **Initial Information**

    - Complete basic business information

3. **Email Verification**
    - Check inbox for verification email
    - Click verification link to activate account
    - Return to portal for onboarding completion

### Onboarding Wizard

The onboarding process consists of four main phases:

**Phase 1: Business Profile**

-   Complete comprehensive questionnaire
-   Define service offerings and expertise
-   Upload business logos and professional photos

**Phase 2: Document Submission**

-   Submit KYV (Know Your Vendor) documents
-   Upload business registration certificates
-   Provide professional licenses and certifications
-   Provide portfolio and rate card

**Phase 3: Vetting Fee Payment**

-   Process required vetting fee (varies by provider type)
-   Choose payment method (card, mobile money)
-   Receive payment confirmation and receipt

**Phase 4: Review & Approval**

-   TRIFIC team reviews application (3-5 business days)
-   Receive approval notification via email
-   Gain full access to provider portal features

## Quick Reference Guide

### Essential Shortcuts

| Action             | Shortcut     | Location         |
| ------------------ | ------------ | ---------------- |
| Dashboard          | Ctrl/Cmd + D | Main navigation  |
| New Message        | Ctrl/Cmd + M | Messaging center |
| Job Search         | Ctrl/Cmd + J | Job board        |
| Profile Edit       | Ctrl/Cmd + P | Account settings |
| Withdrawal Request | Ctrl/Cmd + W | Wallet section   |

### Status Indicators

| Symbol | Meaning           | Context             |
| ------ | ----------------- | ------------------- |
| Green  | Online/Active     | Chat availability   |
| Yellow | Pending Review    | Application status  |
| Red    | Action Required   | Document submission |
| Star   | Featured/Priority | Job opportunities   |
| Lock   | Secure/Encrypted  | Message security    |

### Important Limits & Requirements

-   **Profile completion:** Minimum 80% for job applications
-   **Response time:** Maximum 24 hours for client messages
-   **Document validity:** Annual renewal for business licenses
-   **Minimum withdrawal:** $50 or equivalent in local currency
-   **File upload limit:** 25MB per file, 100MB per submission
