# SDKs

Software Development Kits for integrating with the TRIFIC Platform API.

## Available SDKs

### JavaScript/Node.js SDK

Official SDK for JavaScript and Node.js applications.

### Python SDK

Python SDK for backend integrations.

### PHP SDK

PHP SDK for web applications.

### Mobile SDKs

Native SDKs for iOS and Android development.

## Getting Started

1. Choose your preferred SDK
2. Install the SDK package
3. Configure your API credentials
4. Start building your integration
