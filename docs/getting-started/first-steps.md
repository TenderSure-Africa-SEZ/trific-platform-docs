# First Steps After Installation

Welcome to TRIFIC Platform! Now that you have the platform installed and running, let's walk through the essential first steps to get you productive quickly.

## Quick Orientation

### Understanding Your Role

Before diving in, it's important to understand which portal you'll primarily be using:

-   **Client Portal** - For companies looking to hire service providers
-   **Provider Portal** - For service providers seeking work opportunities
-   **Admin Portal** - For TenderSure staff managing provider vetting
-   **Management Portal** - For TRIFIC leadership overseeing platform operations

## Initial Setup Tasks

### 1. Complete Your Profile

Regardless of your role, a complete profile is essential:

#### For Clients

-   Upload company logo and information
-   Set up billing preferences
-   Define your team structure and permissions
-   Configure notification preferences

#### For Providers

-   Complete business profile with portfolio samples
-   Upload required certifications and documents
-   Set up your rate cards and service offerings
-   Configure availability and communication preferences

### 2. Security Configuration

**Enable Two-Factor Authentication (2FA)**

1. Navigate to Account Settings → Security
2. Click "Enable 2FA"
3. Scan the QR code with your authenticator app
4. Enter the verification code to confirm

**API Access Setup** (if needed)

1. Go to Account Settings → API Keys
2. Generate your first API key with appropriate permissions
3. Store the key securely - it won't be shown again
4. Test your API access with a simple call

### 3. Integration Setup

**Payment Methods** (Clients)

-   Add your preferred payment methods
-   Set up automatic escrow funding if desired
-   Configure approval workflows for large payments

**Bank Account Details** (Providers)

-   Add bank account for payment withdrawals
-   Verify account ownership through micro-deposits
-   Set up notification preferences for payments

### 4. First Actions

#### For New Clients

1. **Browse the Provider Directory**

    - Explore available service categories
    - Review provider profiles and ratings
    - Identify potential partners for your needs

2. **Post Your First Job** (optional)

    - Use our job posting wizard
    - Set clear requirements and budget
    - Choose between public posting or direct invitations

3. **Initiate Direct Engagement**
    - Select a pre-vetted provider
    - Send a direct contract proposal
    - Set up milestone-based payments

#### For New Providers

1. **Complete Your Portfolio**

    - Add work samples and case studies
    - Upload relevant certifications
    - Write compelling service descriptions

2. **Explore Available Jobs**

    - Browse current job postings
    - Set up job alerts for your categories
    - Apply to relevant opportunities

3. **Optimize Your Profile**
    - Add keywords clients search for
    - Set competitive but fair rates
    - Ensure your availability calendar is current

## Understanding the Vetting Process

### For Providers

All providers must complete our rigorous vetting process:

1. **Initial Application** - Basic information and document upload
2. **KYC/KYB Verification** - Identity and business verification
3. **TenderSure Evaluation** - External professional assessment
4. **Approval Decision** - Pass/fail determination
5. **Quarterly Re-evaluation** - Ongoing quality assurance

**Vetting Fee**: A one-time fee is required to begin the vetting process. This ensures serious applicants and covers evaluation costs.

### For Clients

No vetting required! However, we recommend:

-   Completing KYC verification for higher transaction limits
-   Adding team members with appropriate permissions
-   Setting up comprehensive billing and payment preferences
