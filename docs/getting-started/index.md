# Getting Started

Welcome to the Trific Platform documentation. This guide will help you understand the platform architecture, set up your development environment, and get started with the various portals.

## What is Trific?

Trific is a curated marketplace that connects corporate clients with pre-qualified service providers. Unlike traditional bidding marketplaces, Trific enables clients to directly engage vetted service providers without posting jobs.

## Key Features

-   **Vetted Provider Directory**: All providers undergo TenderSure evaluation
-   **Multiple Portals**: Client, Provider, Admin, and Management interfaces
-   **Secure Messaging**: In-app communication for contract discussions
-   **Escrow Payments**: Milestone-based payments with multi-gateway support
-   **Quarterly Re-evaluation**: Continuous quality assurance
